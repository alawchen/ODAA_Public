公文自動歸檔系統設定文件

建立日期：2026-05-13 ／ 最後更新：2026-06-01

一、系統概述

本系統自動掃描指定資料夾中的 PDF 公文，解析各欄位後寫入公文收發紀錄（預設使用 Google Sheets ），並依命名規則複製歸檔至本機磁碟。

項目說明
程式語言Python 3.10+，虛擬環境位於 <程式目錄>\.venv\
執行方式Windows 工作排程器每日 10:00 / 12:00 / 14:00 / 16:00 呼叫 run.bat
PDF 來源依 .env 中 INBOX_DIR 設定（掃描機輸出或手動放置資料夾）
歸檔目的地ARCHIVE_BASE_DIR\{民國年}年\歸檔公文\（依 .env 設定，年份由程式自動建立）
版本管理GitHub 倉庫（.env、credentials.json、processed.json、logs/ 均排除於版控外）

二、目錄結構

<程式目錄>\              ← clone 後自訂放置路徑（BASE_DIR 自動偵測，無需設定）
  ├── main.py                  主控流程
  ├── pdf_parser.py            PDF 文字擷取 + OCR + Gemini 圖片轉換
  ├── field_extractor.py       欄位解析（regex / Gemini Vision / Claude fallback）
  ├── sheets_manager.py        Google Sheets 讀寫
  ├── file_manager.py          命名規則與歸檔
  ├── config.py                所有路徑與常數設定
  ├── run.bat                  Windows 排程呼叫入口（需修改程式目錄路徑）
  ├── env.example.md           .env 設定範本（可入版控）
  ├── .env                     機器設定與金鑰（不入版控，需自行建立）
  ├── credentials.json         Google 服務帳號金鑰（不入版控）
  ├── processed.json           已處理 PDF 清單（防重複，不入版控）
  ├── tessdata\                Tesseract 語言包（不入版控，需手動安裝）
  │   ├── chi_tra.traineddata
  │   └── eng.traineddata
  └── logs\                    每日執行記錄（不入版控）

<INBOX_DIR>\              ← PDF 輸入資料夾（依 .env 設定，可為任意路徑）

<ARCHIVE_BASE_DIR>\
  └── {民國年}年\
      └── 歸檔公文\         ← 歸檔 PDF 輸出位置（依 .env 設定）

三、初始設定：建立 .env 檔案

程式所有機器特定路徑與金鑰均從 .env 讀取。首次設定時，將 env.example.md 的內容複製為 .env，並填入實際值。

⚠ .env 包含 API 金鑰與路徑等識別資訊，已列入 .gitignore，絕對不可 commit 或外傳。
# 公文 PDF 掃描或下載的來源資料夾
INBOX_DIR=<公文 PDF 來源資料夾完整路徑>

# 歸檔根目錄，程式依年份自動建立子目錄（如 {民國年}年\）
ARCHIVE_BASE_DIR=<歸檔根目錄完整路徑>

# 年份目錄下的歸檔子目錄名稱（預設為「歸檔公文」）
ARCHIVE_SUBDIR=<歸檔子目錄名稱>

# Tesseract OCR 執行檔路徑（winget 安裝預設路徑如下）
TESSERACT_CMD=C:\Program Files\Tesseract-OCR\tesseract.exe

# Poppler 執行檔目錄（路徑含版本號，依實際安裝確認）
POPPLER_PATH=C:\Users\<使用者名稱>\AppData\Local\Microsoft\WinGet\Packages\oschwartz10612.Poppler_Microsoft.Winget.Source_8wekyb3d8bbwe\poppler-25.07.0\Library\bin

# Google Sheets 試算表 ID（從試算表網址 /d/<ID>/ 取得）
SPREADSHEET_ID=<試算表_ID>

# Anthropic API Key（可選，僅在 regex 解析不完整時呼叫 Claude Haiku）
ANTHROPIC_API_KEY=<Anthropic_API_Key>

# Google AI Studio API Key（建議設定，掃描件改走 Gemini Vision 辨識）
GOOGLE_API_KEY=<Google_AI_Studio_API_Key>

# 本公司／機關完整名稱；發文機關符合此名稱時自動登記為「發文」（可留空，留空全部視為收文）
OWN_ORG=<公司或機關全名>
建立 .env 後，執行 .venv\Scripts\python.exe main.py 測試；若有必要變數遺漏，程式啟動時會明確列出缺少項目並終止執行。

五、歸檔檔名規則

格式：{流水號}.{民國日期}_{機關名稱}_{主旨摘要}.pdf

範例：NNN.{年}.{月}.{日}_{機關名稱}_{主旨}.pdf
      ─── ─────────── ──────────── ───────────
       │       │            │            │
       │       │            │            └─ 主旨前 40 字（Gemini 精簡後；去除 \ / : * ? " < > | ）
       │       │            └─────────────── 機關名稱（前 10 字；發文時為受文者名稱）
       │       └──────────────────────────── 發文日期（民國年.月.日，月日補零兩位）
       └──────────────────────────────────── 流水號（3 位補零，每年從 001 重置）

歸檔路徑依發文日期民國年決定：（預設）ARCHIVE_BASE_DIR\{民國年}年\歸檔公文\

若目標檔名已存在，自動加上 _dup 後綴避免覆蓋。

六、Google Sheets 結構

試算表依民國年建立分頁（如 114、115、116），分頁不存在時由程式自動建立並寫入標題列。

欄欄位名稱來源
A類型依 OWN_ORG 自動判斷「收文」或「發文」（未設定 OWN_ORG 時固定輸出「收文」）
B收發類型電子公文 / 郵寄（依 PDF 文字量自動判斷）
C收/發文機關自動解析；發文時自動替換為受文者名稱
D收發日期自動解析，格式 YYYY/MM/DD（西元年）
E文號自動解析（發文字號）
F案號人工手動填寫
G主旨自動解析
H備註人工使用
I流水號每年從 001 重置，3 位補零
J歸檔檔名完整歸檔檔名（含 .pdf）
流水號依 J 欄歸檔檔名前綴（如 NNN.{年}.）計算同年最大值 +1，跨年自動重置。

七、Google 服務帳號設定（Sheets 寫入）

  1. 前往 Google Cloud Console → 建立或選擇專案
  2. 啟用 Google Sheets API 與 Google Drive API
  3. 建立服務帳號 → 下載 JSON 金鑰 → 改名為 credentials.json，放至程式目錄
  4. 開啟公文收發試算表 → 右上角「共用」→ 貼入服務帳號 email → 設為編輯者
⚠ credentials.json 含私鑰，請勿上傳至 Git 或雲端共享，僅存放於本機。
程式目錄內附有 credentials.example.json，說明 JSON 金鑰檔的欄位結構供參考。

八、OCR 工具安裝（掃描件 Tesseract fallback 用）

Tesseract

  • 安裝：winget install UB-Mannheim.TesseractOCR
  • 預設安裝路徑：C:\Program Files\Tesseract-OCR\tesseract.exe
  • 語言包需手動複製至程式目錄下的 tessdata\：chi_tra.traineddata、eng.traineddata
  • 安裝完成後，確認 .env 中 TESSERACT_CMD 路徑正確
Tesseract 現為備援（fallback）使用：GOOGLE_API_KEY 未設定，或 Gemini 呼叫失敗時，程式自動改走此路徑。

Poppler（pdf2image 依賴，PDF 轉圖片用）

  • 安裝：winget install oschwartz10612.Poppler
  • 安裝後路徑形如：C:\Users\<使用者名稱>\AppData\Local\Microsoft\WinGet\Packages\oschwartz10612.Poppler_...\poppler-X.XX.X\Library\bin
  • 將完整路徑填入 .env 的 POPPLER_PATH（注意版本號依實際安裝而異）

十、執行流程

電子公文（文字型 PDF）

1
掃描 INBOX_DIR，取得所有 .pdf 清單；載入 processed.json 跳過已處理檔案
2
pdfplumber 擷取文字，套用 Unicode NFKC 正規化；字數 ≥ 50 → 判定為電子公文
3
regex 解析欄位（發文機關、日期、文號、主旨）；解析不完整時呼叫 Claude Haiku API 補充；依 OWN_ORG 自動判斷收/發文類型，發文時以受文者取代機關欄位
4
呼叫 condense_subject()（Gemini）將主旨精簡為 40 字以內，期限計算語句（如「次日起N日曆天」）優先完整保留
5
從 Google Sheets 對應年份分頁 J 欄計算流水號（同年最大值 +1）
6
組合歸檔檔名，複製 PDF 至 ARCHIVE_BASE_DIR\{年}年\歸檔公文\
7
在 Google Sheets 對應年份分頁末尾新增一列（A–J 欄），檔案 SHA256 hash 寫入 processed.json

掃描件（郵寄來文）

1
pdfplumber 擷取字數 < 50 → 判定為掃描件
2
Gemini Vision 路徑（GOOGLE_API_KEY 已設定）：pdf2image 將各頁轉為圖片，一次呼叫 gemini-2.5-flash，直接回傳結構化 JSON 欄位（原文主旨）；依 OWN_ORG 判斷收/發文類型
2
Tesseract fallback（Key 未設定或 Gemini 失敗）：pytesseract OCR（chi_tra+eng）→ CJK 空白清理 → regex 解析
3
呼叫 condense_subject()（Gemini）精簡主旨
4
後續流程與電子公文相同（步驟 5–7）
步驟 5 為「複製」非「移動」，確認歸檔正確後可手動刪除 INBOX_DIR 原檔。

十一、Windows 工作排程器設定

run.bat 內容

將程式 clone 至本機後，修改 run.bat 中的程式目錄路徑：

@echo off
cd /d %~dp0
.venv\Scripts\python.exe main.py >> logs\run.log 2>&1
%~dp0 為 bat 所在目錄，程式 clone 後無需修改路徑，直接放入程式目錄執行即可。

排程設定步驟

  1. 開啟「工作排程器」（taskschd.msc）
  2. 建立基本工作 → 觸發程序選「每天」
  3. 設定 4 個觸發時間：10:00、12:00、14:00、16:00
  4. 動作：執行程式 → 程式（program）填 cmd.exe，引數（arguments）填 /c "<程式目錄>\run.bat"
  5. 一般設定 → 勾選「不管使用者是否登入都要執行」（需輸入帳號密碼）

十二、日常維護

處理後手動作業

  • 開啟 Google Sheets 對應年份分頁，在 F 欄（案號）手動填入內部案件編號
  • 確認歸檔無誤後，可刪除 INBOX_DIR 中的原始 PDF

重新處理已處理的 PDF

processed.json 現以 SHA256 hash 記錄已處理檔案。若需重新處理，直接刪除或清空 <程式目錄>\processed.json，再次執行 run.bat 即可（inbox 中的原檔仍在，重複歸檔時會加 _dup 後綴）。

欄位解析不完整時

Log 出現 欄位解析不完整 警告時，請至 Google Sheets 手動補齊缺少欄位。

新增年份分頁

程式偵測到新年份時自動建立對應分頁並寫入標題列，無需人工操作。

Log 位置

每日執行記錄存於 <程式目錄>\logs\run_YYYYMMDD.log。

十三、模組功能說明

檔案功能
main.py主控流程；偵測掃描件自動切換 Gemini / Tesseract 路徑；以 SHA256 hash 管理 processed.json（自動遷移舊格式）；管理 log
pdf_parser.py電子公文：pdfplumber + NFKC 正規化；掃描件：get_pdf_images() 轉圖（供 Gemini），Tesseract 作 fallback
field_extractor.py電子公文：regex 解析（多行主旨合併 OCR 換行）+ Claude Haiku fallback；掃描件：extract_fields_from_images() 呼叫 Gemini Vision；condense_subject() 精簡主旨（40字，期限語句優先保留）；依 OWN_ORG 判斷收/發文，發文時以受文者取代機關欄位
sheets_manager.pygspread 服務帳號認證；依民國年自動建立分頁；計算流水號；寫入紀錄列
file_manager.py組合歸檔檔名；依年份決定目標資料夾；複製 PDF（重名加 _dup）
config.py所有路徑與常數（讀取 .env，啟動時驗證必要變數）
